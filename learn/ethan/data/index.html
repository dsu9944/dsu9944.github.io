👨‍👩‍👦 For grown-ups

This game covers data from the NSW Mathematics K–10 syllabus: sorting objects into groups, making and reading tally marks, picture graphs where one picture stands for one thing, column graphs (reading values, most and least, how many more), and simple pie charts using only halves and quarters. Later levels build a column graph from a tally, and pick the graph that can answer a question.

Every question is read aloud when it appears (you can turn this off below), and the 🔈 button repeats it. Reading is kept to a minimum. The feedback shows the answer on the graph itself, for example counting along a row or showing the "extra" part of the taller column for "how many more". Hints are free but give 5 points instead of 10. Progress is saved on this device only.
